# BiliPai 路线图

本页只维护优先级、完成条件和非目标；构建、依赖与发布记录分别由构建配置和 `CHANGELOG.md` 负责。

本页描述当前开发方向，不等同于发布承诺。功能是否已经可用以当前源码为准；公开版本与用户可见变更以 `CHANGELOG.md` 和 GitHub Releases 为准。

## 事实边界

- 当前构建、变体和依赖：`app/build.gradle.kts`、根构建配置和版本目录。
- 已发布版本与用户可见变更：`CHANGELOG.md`。
- 当前页面集合：`BiliPaiNavKey.kt` 与 UI 设计页面目录的结构测试。

## 已形成产品基线

- 首页推荐、分区、搜索、动态、消息、空间、历史、收藏、稍后再看和个人中心主流程。
- 普通视频、番剧、直播、离线视频与听视频模式；包含 DASH/HLS、弹幕、倍速、手势、PiP、后台播放和系统媒体控制。
- 视频笔记、AI 总结草稿、时间点、富文本编辑与系统分享。
- 手机、平板和折叠屏布局；MIUIX（默认）、Material 3（可选）与液态玻璃视觉能力。
- 10 个内置插件、JSON 规则插件、外部 `.bpplugin`/皮肤包解析预览、插件 SDK 与示例。
- DLNA、Google Cast、WebDAV 备份、应用内更新、多账号会话切换。
- Navigation3 自持返回栈、预测返回、整卡共享过渡、连续播放器画面与 Baseline Profile/Macrobenchmark 基础设施。

## 当前优先级

### P0：发布与回归闭环

| 方向 | 当前状态 | 完成条件 |
| --- | --- | --- |
| 视频整卡打开/返回稳定性 | 正在收敛 | 所有卡片入口在播放、未播放、暂停及预测返回完成/取消时无黑底、错卡、跳变、双影或黑帧 |
| Navigation3 1.2 兼容 | 已完成依赖对齐，待全入口真机回归 | runtime/UI 保持同版；返回目标 Scene 始终存在；普通返回与预测返回一致 |
| 转场稳态性能 | 正在收敛 | 详情稳态不再更新转场模糊、Backdrop 或来源快照；120Hz 真机达到既定帧预算 |
| AGP 9 单元测试回归 | 持续回归 | 受影响模块的定向测试和必要的扩展测试保持可运行，新增问题有最小复现 |
| Release 候选验证 | 待上述项目完成 | dev/release 候选通过启动、播放、返回、下载、插件、平板和隐私权限清单 |

### P1：体验与工程质量

- 扩展视频详情 Macrobenchmark，长期覆盖打开、稳态、返回、预测取消和连续八次往返。
- 收敛首页、动态、播放器和设置中的帧级状态读取、图层数量与高成本模糊路径。
- 完成 MIUIX / Material 3 双主题在组件语义、可访问性、暗色主题和大屏布局上的一致性回归。
- 继续拆分过大的 feature 状态持有者，将纯策略下沉到可单测的 Policy/UseCase。
- 把路线图、功能矩阵、架构、QA 与发布流程纳入每次版本同步检查。

### P2：能力完善

- 外部 `.bpplugin` 从解析预览推进到可控执行：明确签名、能力授权、隔离、版本兼容和失败回滚边界。
- 多账号从“会话切换”推进到缓存、历史、下载、推荐反馈和部分设置的按账号隔离。
- 补齐英文与繁体中文资源，逐步清除页面硬编码文案。
- 增强收藏夹批量管理、筛选和跨入口一致性。
- 评估观看历史云同步；只有在账号、隐私、冲突合并和离线策略明确后进入实现。

## 后续候选

- 直播礼物、上舰、房间状态、播放源刷新等更多实时事件语义。
- 更完整的 TV/键盘/遥控器焦点导航与大屏播放器体验。
- 性能基线自动比较和更稳定的设备测试矩阵。
- 插件社区索引、兼容性声明与示例覆盖扩展。

## 不采用的捷径

- 不通过降低整卡模糊强度、关闭实时播放器返回或切换为不兼容 Surface 路径换取表面性能。
- 不让封面、标题、UP 和统计各自拥有相互竞争的 bounds 动画。
- 不把外部插件预览描述成已可安全执行，也不把多账号会话切换描述成完整数据隔离。
- 不以开发版本号、路线图状态或本地构建代替正式发布记录。

## 维护规则

发生以下变化时必须更新本页：

1. 功能在“预览 / 开发中 / 已完成”之间迁移。
2. Release 阻塞项完成、取消或改变验收标准。
3. 模块职责、插件执行边界、账号隔离或隐私行为发生变化。
4. 页面集合、版本或依赖变化影响到本页的优先级或完成条件。

修改后运行 `scripts/verify_docs.ps1`；只同步受影响的状态文档，不在 README 或 AI 入口复制构建事实。
