## 初学者解释

个人页展示“我是谁和我能管理什么”，内容库管理历史、收藏、点赞、稍后再看和下载。这里的操作常会修改数据，所以浏览态、选择态、删除范围与撤销结果必须明确。

## 规范要求

- 本人页面与他人空间使用不同动作语义，不能向他人空间显示本地账号管理入口。
- 删除、批量删除、移出收藏和删除本地文件必须说明对象、范围和能否恢复。
- 列表局部操作后 UI 必须与数据结果一致，不能只视觉移除或误删其他集合。

## P025 我的档案

- **用户目标**：查看当前账号摘要、常用内容库和设置入口，切换或退出账号。
- **入口与出口**：主导航进入；出口到登录、设置、历史、收藏/合集、关注、下载、稍后再看、消息、视频、番剧。
- **信息层级**：账号身份与登录状态 > 高频服务入口 > 内容摘要 > 设置与账号操作。
- **文字线框**：`账号头 / 服务网格或列表 / 内容预览 / 设置与退出`。
- **设备适配**：Compact 纵向；Expanded 可身份侧栏+内容主区，服务项不做过大的营销卡。
- **组件清单**：身份头、头像、`UserLevelBadge`、服务入口、内容卡、`AppListItem`、确认 Dialog。
- **状态矩阵**：首次加载=身份和服务稳定占位；刷新=保留结构；正常=已登录数据；部分数据=某服务摘要失败局部提示；空=内容库各自空；失败=账号摘要失败可重试；离线=本地账号摘要+受限标识；未登录=清楚登录入口与可用服务；权限不足=下载/通知等按功能说明；禁用=受限服务说明；分页加载/结束=内容预览若分页按列表规则。
- **交互和返回**：主目的地返回首页/根规则一致；退出需确认并刷新所有账号可见状态；账号切换不得残留上一账号身份。
- **权限/登录**：登录凭据不展示/记录；多账号切换需明确当前账号，不能承诺尚未实现的完全数据隔离。
- **性能**：各摘要并行但局部更新；头像和背景按尺寸；不因一个服务失败重组全部页面。
- **无障碍**：身份、等级、会员与账号操作分开读；服务入口有名称和状态；退出为明确危险动作。
- **当前差距**：账号切换后的业务缓存隔离并不完整，文案和 UI 不得暗示完全隔离。
- **验收**：未登录、登录、切换账号、退出、某摘要失败；预期身份与各入口即时一致且无旧账号残留。

## P026 历史记录档案

- **用户目标**：按观看历史找到内容、续播并管理记录。
- **入口与出口**：底栏或个人页进入；出口到视频、番剧、直播、文章/动态、用户空间与返回。
- **信息层级**：日期/类型分组 > 内容标题与观看进度 > 作者/时间 > 管理操作。
- **文字线框**：`顶部栏+管理 / 筛选 / 历史列表 / 分页`。
- **设备适配**：Compact 列表/卡；Expanded 提高信息密度但保持进度和操作清晰。
- **组件清单**：`CommonListScreen`、历史卡/行、进度、筛选、选择模式、确认 Dialog、Snackbar。
- **状态矩阵**：首次加载=行占位；刷新=保留；正常=记录；部分数据=封面/统计缺失仍可续播；空=暂无历史；失败=重试；离线=本地缓存/同步状态；未登录=本地或登录策略明确；权限不足=不适用；禁用=失效内容不可播；分页加载/结束=尾部。
- **交互和返回**：点击按内容类型进入正确目的地并恢复进度；删除单条/批量范围明确；底栏重复点击可回顶。
- **权限/登录**：账号历史与本地历史边界按实际能力说明，不伪装同步。
- **性能**：稳定记录 ID；进度局部更新；不同内容类型解析不阻塞滚动。
- **无障碍**：读出标题、类型、观看进度和时间；删除动作说明对象。
- **当前差距**：历史可跳转多种内容，路由回退和进度字段需要持续验证。
- **验收**：分别点击视频/PGC/直播/文章历史并返回，删除单条；预期路由、续播、列表位置和数据一致。

## P027 收藏档案

- **用户目标**：浏览收藏夹和收藏内容，进入详情或听视频。
- **入口与出口**：个人/首页进入；出口到合集详情、视频、用户空间、音频播放和返回。
- **信息层级**：收藏夹选择 > 当前集合内容 > 收藏状态/进度 > 管理动作。
- **文字线框**：`顶部栏 / 收藏夹 chips/列表 / 当前收藏内容 / 分页`。
- **设备适配**：Compact 收藏夹横向/弹层选择；Expanded 可文件夹侧栏+内容网格。
- **组件清单**：`CommonListScreen`、收藏夹 chip、合集行、视频卡、选择/排序、状态组件。
- **状态矩阵**：首次加载=文件夹与内容占位；刷新=保留当前夹；正常=收藏内容；部分数据=某文件夹或封面失败局部；空=当前夹为空；失败=文件夹/内容分别重试；离线=缓存标记；未登录=登录；权限不足=私密/失效说明；禁用=不可访问集合；分页加载/结束=尾部。
- **交互和返回**：切换文件夹保留各位置；移出收藏只影响目标；合集进入独立档案；听视频建立明确播放列表。
- **权限/登录**：账号收藏必须登录；私密集合不泄露内容。
- **性能**：文件夹与内容请求分离；网格稳定 key；大收藏分页有界。
- **无障碍**：当前文件夹选中可读；收藏状态和观看进度有文字语义。
- **当前差距**：收藏夹、订阅合集与视频列表共享 `CommonListScreen`，模式边界复杂。
- **验收**：切换空/非空收藏夹、进入合集、移出一项并返回；预期只更新目标集合且位置合理。

## P028 点赞视频档案

- **用户目标**：浏览自己点过赞的视频并继续播放。
- **入口与出口**：个人/首页进入；出口到视频和用户空间。
- **信息层级**：列表标题 > 视频内容 > 点赞/观看状态 > 分页。
- **文字线框**：`顶部栏 / 视频列表网格 / 分页`。
- **设备适配**：遵循通用列表与视频卡网格。
- **组件清单**：`CommonListScreen`、视频卡、加载/空/错误、分页。
- **状态矩阵**：首次加载=占位；刷新=保留；正常=点赞视频；部分数据=统计缺失；空=暂无点赞视频；失败=重试；离线=缓存/受限；未登录=登录；权限不足=失效内容说明；禁用=不可播项；分页加载/结束=尾部。
- **交互和返回**：打开视频返回恢复位置；取消点赞后的列表结果按产品策略即时一致。
- **权限/登录**：必须登录。
- **性能**：稳定 bvid/记录 key，分页去重。
- **无障碍**：标题、作者、点赞与播放状态可读。
- **当前差距**：与收藏/历史共用列表框架，空状态和管理动作仍需统一。
- **验收**：空、有数据、分页失败、视频返回；预期状态和位置一致。

## P063 历史搜索档案

- **用户目标**：在观看历史中按关键词找到并进入特定内容。
- **入口与出口**：历史记录页搜索框进入，携带查询参数；出口到对应内容（视频/番剧/直播/文章等）或返回历史列表，返回保留查询。
- **信息层级**：查询 > 匹配标题 > 内容类型/观看进度 > 时间。
- **文字线框**：`返回+搜索框 / 结果列表 / 空或错误`。
- **设备适配**：Compact 全页；Expanded 提高密度但保持进度可见。
- **组件清单**：`CommonListScreen` 搜索模式、`AppSearchField`、历史行/卡、空状态。
- **状态矩阵**：首次加载=等待输入；刷新=不适用；正常=匹配记录；部分数据=元数据缺失仍可定位续播；空=无匹配建议改词；失败=重试；离线=本地历史可搜索；未登录=本地或登录策略与历史页一致；权限不足=不适用；禁用=失效内容不可播；分页加载/结束=有界结果。
- **交互和返回**：点击按内容类型进入正确目的地并恢复进度；清空只清查询；返回恢复历史列表位置。
- **权限/登录**：搜索不请求权限；账号与本地历史边界与历史页一致。
- **性能**：本地索引有界，输入防抖，避免每键全量过滤。
- **无障碍**：字段标签、清空动作、结果标题/类型/进度可读。
- **当前差距**：结果路由与历史回退需随历史列表页持续核对。
- **验收**：搜索关键词、点结果、清空、返回；预期定位准确、查询保留、进度一致。

## P031 关注列表档案

- **用户目标**：浏览某个用户的关注关系并进入用户空间。
- **入口与出口**：个人或用户空间进入，携带用户 ID；出口到目标用户空间和返回。
- **信息层级**：列表所有者/标题 > 用户身份 > 关注状态/简介 > 分页。
- **文字线框**：`顶部栏 / 搜索或筛选（若有）/ 用户列表 / 分页`。
- **设备适配**：Compact 单列，Expanded 限宽或多列但身份信息不拆散。
- **组件清单**：`FollowingListScreen`、用户 `AppListItem`、头像、等级/身份、关注按钮、状态组件。
- **状态矩阵**：首次加载=用户行占位；刷新=保留；正常=关注用户；部分数据=简介缺失；空=暂无关注；失败=重试；离线=缓存/受限；未登录=公开列表按服务能力，否则登录；权限不足=隐私列表说明；禁用=封禁/失效用户；分页加载/结束=尾部。
- **交互和返回**：用户行进入空间，关注按钮不触发整行；返回恢复所有者空间。
- **权限/登录**：隐私与关注操作按账号要求；不泄露不可见关系。
- **性能**：用户 ID 稳定 key，头像按尺寸。
- **无障碍**：读出用户名称、简介、关注状态；按钮状态随操作更新。
- **当前差距**：用户等级/身份标签仍有重复实现，关注按钮状态需统一。
- **验收**：公开、私密、空和分页列表；预期隐私说明、按钮与跳转准确。

## P032 下载列表档案

- **用户目标**：查看离线任务进度，暂停/重试/删除并播放完成项。
- **入口与出口**：个人/首页进入；出口到离线播放器、在线视频详情和返回。
- **信息层级**：任务状态分组 > 标题/清晰度 > 进度/错误 > 控制。
- **文字线框**：`顶部栏+管理 / 下载中 / 已完成 / 任务行 / 存储与错误提示`。
- **设备适配**：Compact 列表，Expanded 可双列但进度与控制稳定；系统文件/目录选择用合适弹层。
- **组件清单**：`DownloadListScreen`、任务行、`AppProgress`（目标/现有进度入口）、按钮、Dialog/Sheet、状态组件。
- **状态矩阵**：首次加载=读取本地任务，短暂稳定进度；刷新=同步任务不清空；正常=任务按状态展示；部分数据=封面/元信息缺失仍显示文件任务；空=暂无下载；失败=任务级重试；离线=下载暂停/失败明确，已完成可播；未登录=已有本地任务可见，新任务权限按服务；权限不足=存储/通知原因；禁用=空间不足或任务状态不允许；分页加载/结束=本地列表通常不适用。
- **交互和返回**：暂停/继续/删除只影响目标；批量删除说明本地文件；进度不得跳异常百分比；失败重试可恢复。
- **权限/登录**：按 Android 版本请求必要权限；路径与账号信息不进普通日志。
- **性能**：进度更新节流并局部重组；本地文件检查不阻塞 UI；封面缓存有界。
- **无障碍**：读出任务名、百分比、状态与动作；进度不靠颜色。
- **当前差距**：进度组件目标入口和权限降级文案仍需统一。
- **验收**：下载中断恢复、失败重试、删除、播放完成项；预期任务与本地文件结果一致。

<a id="p048"></a>
## P048 合集/收藏夹详情档案

- **用户目标**：浏览一个合集、系列或收藏夹的内容并按顺序播放。
- **入口与出口**：个人收藏/空间进入，携带类型、ID、所有者与标题；出口到视频、用户空间与返回。
- **信息层级**：合集身份/所有者 > 简介与统计 > 内容列表 > 播放进度。
- **文字线框**：`返回+标题 / 合集头 / 内容列表网格 / 分页`。
- **设备适配**：Compact 头+列表；Expanded 可头侧区+内容主区，封面比例稳定。
- **组件清单**：合集头、用户身份、视频列表、播放入口、加载/空/错误、共享元素（支持时）。
- **状态矩阵**：首次加载=头与列表占位；刷新=保留；正常=合集；部分数据=简介/封面缺失；空=合集无内容；失败=重试；离线=缓存/受限；未登录=公开合集或登录；权限不足=私密/下架说明；禁用=失效项；分页加载/结束=尾部。
- **交互和返回**：播放列表顺序与 UI 一致；共享元素不可用时普通转场；返回恢复收藏来源。
- **权限/登录**：私密收藏按权限，不泄露标题/内容。
- **性能**：列表分页、稳定内容 ID；头部不随列表重组。
- **无障碍**：合集标题、作者、项数、当前播放进度与每项状态可读。
- **当前差距**：`SeasonSeriesDetail` 同时承载多类型，类型差异和 shared transition 需保持明确。
- **验收**：favorite/series 类型、空集合、无权限和共享转场开关；预期数据合同与返回都正确。

<a id="p056"></a>
## P056 用户空间档案

- **用户目标**：了解指定用户并浏览其主页、投稿、动态、收藏等分区。
- **入口与出口**：搜索、动态、视频作者、关注列表等进入；出口到关注、视频、番剧、合集和返回来源。
- **信息层级**：用户身份与关系 > 简介/统计 > 内容 Tab > 当前内容流。
- **文字线框**：`返回 / 用户头+关注 / Tab / 当前内容列表网格`。
- **设备适配**：Compact 头随页面滚动；Expanded 可固定身份摘要+内容，Tab 保持同一信息顺序。
- **组件清单**：头像、`UserLevelBadge`、身份/会员、关注按钮、`AppScrollableTabRow`、视频/动态/收藏卡、状态组件。
- **状态矩阵**：首次加载=身份与内容占位；刷新=保留当前 Tab；正常=空间内容；部分数据=某 Tab 失败局部；空=当前分区无内容；失败=身份失败整页重试；离线=缓存身份/内容；未登录=公开浏览，关注时引导；权限不足=私密/封禁说明；禁用=不可关注或内容失效；分页加载/结束=当前 Tab 尾部。
- **交互和返回**：Tab 切换保留各位置；目标 bvid 可定位；关注状态即时可信；返回准确来源。
- **权限/登录**：本人/他人操作不同；关注需登录；隐私空间不泄露内容。
- **性能**：身份头与 Tab 内容解耦；各列表稳定 key；沉浸背景按设备档位降级。
- **无障碍**：身份、统计、关系状态和 Tab 顺序清楚；折叠头不重复读同一名称。
- **当前差距**：沉浸背景、Tab 多布局与网格/单列切换有较高复杂度。
- **验收**：本人/他人、未登录、私密、不同 Tab、网格/单列和返回；预期关系与位置保持。

## 验收方法

使用测试账号与可恢复数据检查浏览、筛选、详情返回、单项/批量管理、空/离线/失败；删除任何材料前明确范围，不使用真实不可恢复的重要数据。
