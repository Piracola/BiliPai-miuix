## 初学者解释

视频页面同时包含“详情阅读”和“媒体播放”两类任务。播放器画面必须稳定，详情和评论可以分区加载；某个次要接口失败不能让正在播放的视频突然消失。Story 和离线播放器共用播放原则，但数据来源和导航行为不同。

## 规范要求

- 普通详情、竖屏直达、音频起播、全屏和续播参数都必须落到同一个明确 session，不重复起播。
- 宽屏媒体断点只改变播放器、详情与评论的排布，不改变功能和信息顺序。
- 预测返回取消后页面、模糊、缩放、来源卡与播放器所有权必须完全恢复。

<a id="p033"></a>
## P033 离线视频播放档案

- **用户目标**：在无网络时播放已完成的本地下载，并查看基本标题、进度和控制。
- **入口与出口**：从下载列表携带任务 ID 进入；返回下载列表，必要时可去任务错误说明。
- **信息层级**：本地媒体画面 > 播放控制/进度 > 标题与离线信息 > 错误恢复。
- **文字线框**：`返回 / 固定媒体区域 / 播放状态层 / 进度与控制 / 本地元信息`。
- **设备适配**：Compact 竖屏嵌入/全屏；横屏沉浸；Expanded 保持媒体比例，不用在线详情多栏强塞无数据区。
- **组件清单**：本地播放器 surface、`PlayerActionButton` 目标组件、进度、`PlayerStatusOverlay` 目标组件、`AppTopBar`。
- **状态矩阵**：首次加载=读取任务和文件；刷新=不适用；正常=本地播放；部分数据=封面/标题缺失仍可播；空=任务无有效文件时按错误处理；失败=文件缺失/解码失败并返回或重试；离线=正常主场景；未登录=本地任务仍可按实际权限播放；权限不足=文件访问原因与设置入口；禁用=不可用控制禁用；分页加载/结束=不适用。
- **交互和返回**：播放/暂停/拖动/全屏状态一致；返回先退出全屏再离开；文件丢失不循环重试。
- **权限/登录**：只请求当前 Android 版本实际需要的文件权限；路径和媒体信息不进入普通日志。
- **性能**：不读取整个媒体到内存；播放器释放跟随页面/session；进度更新节流。
- **无障碍**：控制名称与状态准确；进度可调整；错误可读且有返回下载列表动作。
- **当前差距**：离线播放器与在线播放器的控制/状态组件尚未完全共享语义入口。
- **验收**：飞行模式播放完成项、暂停续播、拖动、旋转、删除文件后打开；预期正常离线播放或明确可恢复错误。

<a id="p046"></a>
## P046 竖屏故事流档案

- **用户目标**：连续上下浏览竖屏视频，快速互动并进入搜索或用户空间。
- **入口与出口**：首页、底栏或直达参数进入；出口到视频详情/相关内容、用户空间、搜索及返回来源。
- **信息层级**：当前全屏视频 > 播放/作者/标题 > 互动操作 > 下一条预加载。
- **文字线框**：`全屏媒体 Pager / 顶部返回搜索 / 右侧互动 / 底部标题作者进度`。
- **设备适配**：Compact 竖屏为主；横屏/Expanded 不把手机竖屏流横向拉伸，应居中媒体并保留安全操作区。
- **组件清单**：竖向 Pager、播放器 surface、作者/标题、互动按钮、进度、加载/错误层、`AppIconButton`。
- **状态矩阵**：首次加载=种子视频或首条占位；刷新=重建推荐但保留当前明确策略；正常=当前播放+邻项；部分数据=标题/互动失败不停止可播媒体；空=暂无推荐并返回/重试；失败=当前项可重试并允许滑过；离线=无缓存时明确失败；未登录=公开播放，互动引导；权限不足=受限视频说明；禁用=下架项不可播并可继续；分页加载=尾部预加载；分页结束=停止无限请求并说明。
- **交互和返回**：上下滑切视频，水平/边缘返回不冲突；单击控制、双击等有按钮替代；返回使用来源 route，取消预测返回恢复当前播放。
- **权限/登录**：基础播放不强制登录；互动按需登录；自动声音策略遵守用户设置。
- **性能**：只保持当前和有限邻项播放器/数据；离屏媒体及时释放；预加载有界；不让每项实时模糊。
- **无障碍**：提供下一/上一视频普通动作；互动按钮有名称和状态；标题不被控制层遮挡。
- **当前差距**：Story 与普通详情的 session 交接、来源返回和竖屏手势需要持续真机验证。
- **验收**：连续滑动 10 条、快速返回取消、打开用户/搜索再返回；预期只一条发声、无黑屏/泄漏、来源准确。

<a id="p053"></a>
## P053 视频详情与播放档案

- **用户目标**：播放视频，了解标题/作者/简介，完成点赞投币收藏、选分 P、看评论和推荐。
- **入口与出口**：首页、搜索、历史、分类、动态、深链等进入；参数支持 cid、音频、竖屏、全屏、续播、评论定位与来源 route；出口到用户空间、相关视频、音频模式、登录和返回来源。
- **信息层级**：播放器与关键播放状态 > 标题/作者 > 互动与分 P > 简介/评论/推荐。会员/画质限制在相关控制附近说明。
- **文字线框**：Compact 为 `媒体 / 标题作者互动 / 分P / 评论推荐`；Expanded 为 `媒体+关键详情 / 侧栏分P或推荐 / 评论`；1600dp 可多区域但正文保持最大宽度。
- **设备适配**：嵌入 16:9、竖屏直达、横屏全屏、宽屏媒体特例都有明确回退；键盘/评论 Sheet 不遮播放器关键退出。
- **组件清单**：`VideoDetailScreen`、播放器 section、`VideoSettingsPanel`、目标 `PagesSelector`、互动按钮、评论 Sheet、推荐卡、迷你播放器、状态层。
- **状态矩阵**：首次加载=封面/媒体壳立即稳定并加载元数据；刷新=局部刷新详情不重建 session；正常=播放+详情；部分数据=评论/推荐/统计失败局部处理；空=无分 P/评论按各区空，不把视频判空；失败=播放源失败与详情失败分开，提供重试/降级；离线=缓存可用则播，否则明确；未登录=公开播放，会员画质/互动引导登录；权限不足=投屏/PiP/通知等按功能解释；禁用=受限画质/互动按钮状态清楚；分页加载/结束=评论/推荐各自尾部。
- **交互和返回**：播放/暂停/进度/手势/设置/分 P 不争抢；相关视频详情可连续导航；顶部、系统、预测返回结果一致；取消预测返回恢复详情和 session。
- **权限/登录**：画质按账号权限展示；登录成功后可刷新能力但不丢播放位置；PiP/通知/投屏按需说明。
- **性能**：播放器 surface 单一所有权；组合期不解析大弹幕；评论/推荐懒加载；共享元素稳定后停止后台快照/模糊工作。
- **无障碍**：播放控制动态命名；进度可调；标题可完整展开；互动读出状态与数值；评论关系可理解；手势均有替代。
- **当前差距**：播放器、预测返回、整卡 morph、评论弹层和多布局是项目最高复杂 UI；`ActionButton` 与 `PagesSelector` 尚有重复。
- **验收**：覆盖未登录/普通/大会员、单P/多P、播放源失败、评论失败、全屏/PiP/后台、相关视频、三种返回、宽屏/平板断点；预期无状态串线、黑底或双播放器。

## 代码映射

- 离线播放：`feature/download/OfflineVideoPlayerScreen.kt`
- 返回与共享元素：Navigation 3 card morph / predictive back policies

## 当前差距

播放器领域专用能力多，统一目标是共享状态、触摸、Token 和双主题合同，而不是把视频、Story 与离线强制合成一个 Screen。

## 验收方法

先运行播放器策略测试，再由用户按三个档案进行文字验收。不得读取或要求截图；重点记录 session 是否唯一、控制是否可达、返回后来源与进度是否正确。
