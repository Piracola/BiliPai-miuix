## 初学者解释

直播是实时内容，番剧强调季度/剧集与会员权限，音频强调队列和后台播放。三者都使用媒体控制，但不能混淆状态：直播没有普通意义的“播放结束进度”，番剧选集不是视频分 P，音频后台仍需保持系统媒体信息一致。

## 规范要求

- 直播、番剧、音频分别保留领域数据合同，共享触摸、状态反馈、生命周期和系统媒体语义。
- 播放队列、选集与当前 UI 必须一致；切后台、锁屏和回前台不得反向触发状态。
- 未登录/会员限制是权限状态，不得显示成网络错误或无限加载。

## P003 听视频首页档案

- **用户目标**：从收藏等来源选择视频作为音频播放队列，并进入正在播放。
- **入口与出口**：主导航进入；出口到视频详情音频起播和登录。
- **信息层级**：正在播放摘要 > 来源/播放列表 > 曲目标题作者 > 播放状态。
- **文字线框**：`听视频顶部 / 正在播放卡 / 来源与曲目列表 / 分页状态`。
- **设备适配**：Compact 单列；Expanded 可队列+现在播放双栏，封面不无限放大。
- **组件清单**：`ListenVideoRoute`、曲目卡、迷你播放器、播放按钮、列表状态。
- **状态矩阵**：首次加载=来源和曲目占位；刷新=保留队列；正常=可选曲目；部分数据=封面/作者缺失仍可播；空=来源无视频并给入口；失败=重试；离线=已缓存/当前媒体按实际可用；未登录=登录引导；权限不足=受限音质说明；禁用=不可播曲目；分页加载/结束=来源列表尾部。
- **交互和返回**：点击曲目建立顺序正确队列并以音频模式进入详情；当前曲目重复点击不重建 session。
- **权限/登录**：收藏来源需要登录；后台播放/通知按需权限。
- **性能**：队列转换一次并稳定；封面按尺寸；不为每行创建播放器。
- **无障碍**：读出曲目、作者、当前播放和不可用原因。
- **当前差距**：听视频与视频详情音频模式的导航/session 所有权复杂。
- **验收**：从不同来源点击中间曲目、切后台再返回；预期队列顺序、当前项和通知一致。

## P034 直播首页档案

- **用户目标**：发现正在直播的房间，并进入搜索、分区或关注直播。
- **入口与出口**：首页/底栏进入；出口到直播间、直播搜索、分区、关注直播和用户空间。
- **信息层级**：搜索/分区导航 > 推荐直播 > 主播/标题 > 热度与状态。
- **文字线框**：`顶部搜索 / 分区与关注入口 / 直播网格 / 刷新分页`。
- **设备适配**：Compact 网格保证封面比例；Expanded 增列并限制卡宽。
- **组件清单**：`LiveListScreen`、直播卡、搜索入口、分区导航、PullToRefresh、状态组件。
- **状态矩阵**：首次加载=直播卡占位；刷新=保留；正常=直播流；部分数据=热度/封面缺失；空=暂无推荐；失败=重试；离线=缓存列表但房间不可播说明；未登录=公开推荐；权限不足=不适用；禁用=已下播卡说明；分页加载/结束=尾部。
- **交互和返回**：点击房间传递 site/room/title/uname；已下播时不进入无限加载；返回恢复网格。
- **权限/登录**：公开浏览不强制登录，关注列表按需登录。
- **性能**：卡片图片按网格加载；在线人数更新节流；列表稳定 room ID。
- **无障碍**：读出直播标题、主播、状态、热度；直播中不只用红色。
- **当前差距**：直播卡与首页直播卡外观/状态可能不同，需要共享语义检查。
- **验收**：刷新时进入/结束的房间、断网和返回；预期状态更新不跳错卡。

## P035 直播搜索档案

- **用户目标**：按关键词找到直播间或主播。
- **入口与出口**：直播首页进入；出口到直播间/用户空间和返回。
- **信息层级**：查询 > 结果类别 > 房间/主播结果 > 分页。
- **文字线框**：`返回+搜索框 / 结果筛选 / 直播结果 / 分页`。
- **设备适配**：遵循搜索母版，宽屏结果限宽/网格。
- **组件清单**：`AppSearchField`、直播卡、用户行、Tab、状态组件。
- **状态矩阵**：首次加载=历史/空查询；刷新=保留查询；正常=结果；部分数据=某类别失败；空=无结果并可改词；失败=重试；离线=历史可用；未登录=公开搜索；权限不足=不适用；禁用=空查询；分页加载/结束=尾部。
- **交互和返回**：IME 提交、清空、详情返回保持查询和位置。
- **权限/登录**：不强制登录。
- **性能**：查询防抖取消旧请求，结果稳定 key。
- **无障碍**：字段、清空、类别和直播状态完整可读。
- **当前差距**：与综合搜索的输入/状态复用程度需持续收口。
- **验收**：快速改词、空结果、房间下播和返回；预期无旧结果覆盖。

## P036 直播分区档案

- **用户目标**：浏览直播大分区并选择具体区域。
- **入口与出口**：直播首页进入；出口到分区详情和返回。
- **信息层级**：大分区 > 子分区名称/图标 > 可选热度。
- **文字线框**：`顶部栏 / 分区网格 / 加载错误`。
- **设备适配**：网格列数随宽度变化，单元触摸区 48dp 且图标/文字稳定。
- **组件清单**：`LiveAreaScreen`、分区网格项、加载/空/错误。
- **状态矩阵**：首次加载=网格占位；刷新=保留；正常=区域；部分数据=图标失败保留名称；空=暂无分区；失败=重试；离线=缓存；未登录/权限不足=不适用；禁用=不可用分区；分页加载/结束=通常不适用。
- **交互和返回**：点击携带 parent/area/title，防重复 push；返回直播首页。
- **权限/登录**：不需要登录。
- **性能**：图标按格加载，分区数据缓存。
- **无障碍**：分区名称为主，图标装饰；网格顺序清楚。
- **当前差距**：分区图标与网格尺寸 Token 尚未正式化。
- **验收**：不同宽度、图标失败、空/失败；预期名称和点击始终可用。

## P037 直播分区详情档案

- **用户目标**：浏览指定直播区域的房间并进入播放。
- **入口与出口**：分区页进入；出口到直播间/用户空间和返回。
- **信息层级**：区域标题 > 筛选/排序 > 房间卡 > 分页。
- **文字线框**：`返回+区域名 / 筛选 / 直播网格 / 分页`。
- **设备适配**：卡片网格按宽度增列，标题和直播状态不被裁掉。
- **组件清单**：`LiveAreaDetailScreen`、直播卡、筛选、状态组件。
- **状态矩阵**：首次加载=标题+占位；刷新=保留；正常=房间列表；部分数据=热度缺失；空=区域暂无直播；失败=重试；离线=缓存/不可播说明；未登录=公开；权限不足=不适用；禁用=已下播；分页加载/结束=尾部。
- **交互和返回**：筛选变化可预期，直播返回恢复位置；无效 area 安全错误。
- **权限/登录**：不强制登录。
- **性能**：room ID 稳定 key，在线数据节流。
- **无障碍**：区域标题、筛选值、房间状态可读。
- **当前差距**：直播区域与首页卡片策略需统一。
- **验收**：有效/无效区域、空、分页和下播；预期错误不崩溃。

## P038 关注的直播档案

- **用户目标**：快速找到已关注且正在直播的主播。
- **入口与出口**：直播首页进入；出口到直播间、用户空间、登录。
- **信息层级**：正在直播 > 主播 > 房间标题/状态 > 未开播关注（若展示）。
- **文字线框**：`顶部栏 / 关注直播列表 / 刷新分页`。
- **设备适配**：Compact 列表/网格；Expanded 限卡宽。
- **组件清单**：`LiveFollowingScreen`、直播卡、用户身份、状态组件。
- **状态矩阵**：首次加载=占位；刷新=保留；正常=关注直播；部分数据=房间信息缺失；空=暂无关注开播；失败=重试；离线=缓存；未登录=登录；权限不足=不适用；禁用=已下播；分页加载/结束=尾部。
- **交互和返回**：房间下播更新不误开；返回直播首页。
- **权限/登录**：必须登录。
- **性能**：状态轮询有界并节流。
- **无障碍**：明确“正在直播/未开播”，不只靠颜色。
- **当前差距**：关注直播刷新频率与空状态需验证。
- **验收**：未登录、无人开播、开播/下播变化；预期状态和入口正确。

## P047 视频音频模式档案

- **用户目标**：只听当前视频音轨，使用队列、进度、睡眠计时和后台播放。
- **入口与出口**：从视频详情/听视频进入，携带 bvid/cid/续播位置；返回时 session 交接不重复。
- **信息层级**：封面/标题 > 播放控制和进度 > 队列/模式 > 次要操作。
- **文字线框**：`顶部返回 / 封面标题 / 进度 / 主控制 / 队列与计时器`。
- **设备适配**：Compact 纵向音乐布局；Expanded 封面与控制并排且限制封面；横屏不遮操作。
- **组件清单**：`AudioModeScreen`、音频播放器、进度、播放模式、计时 Dialog、队列、系统媒体会话。
- **状态矩阵**：首次加载=恢复 source 与位置；刷新=不适用；正常=播放；部分数据=封面缺失仍播；空=无可播项按错误；失败=源失败可重试/返回；离线=缓存可播否则说明；未登录=按清晰度权限；权限不足=通知/后台原因；禁用=无上/下一首；分页加载/结束=队列加载按来源。
- **交互和返回**：播放、进度、上一/下一、循环、计时一致；切后台/锁屏与通知同步；返回到视频不双重起播。
- **权限/登录**：后台媒体通知按系统要求；高音质限制明确。
- **性能**：音频 session 单一；封面背景效果可降级；进度节流。
- **无障碍**：控制动态命名、队列当前位置和计时剩余可读。
- **当前差距**：音频模式与 MusicDetail 的 UI/队列能力有重复但数据来源不同。
- **验收**：从视频位置进入、切曲、锁屏、计时结束、返回视频；预期位置与系统媒体一致。

## P049 番剧首页档案

- **用户目标**：发现番剧、查看追番/时间表并搜索或筛选。
- **入口与出口**：首页/个人进入，携带初始类型；出口到番剧详情、播放器、登录和返回。
- **信息层级**：类型/追番/时间表 > 重点番剧 > 列表卡 > 筛选。
- **文字线框**：`顶部/搜索 / 类型Tab / 追番与时间表 / 番剧网格 / 分页`。
- **设备适配**：Compact 卡片网格；Expanded 增列且封面比例稳定。
- **组件清单**：`BangumiScreen`、`BangumiModeTabs`、筛选、番剧卡、状态组件。
- **状态矩阵**：首次加载=各区占位；刷新=保留类型；正常=番剧内容；部分数据=时间表/追番局部失败；空=当前类型无内容；失败=重试；离线=缓存；未登录=公开发现，追番引导；权限不足=会员标签不等错误；禁用=下架项；分页加载/结束=列表尾部。
- **交互和返回**：类型切换保持明确；番剧详情返回位置；登录后刷新追番而不丢当前类型。
- **权限/登录**：追番需登录，会员状态仅影响受限能力。
- **性能**：多 section 分开加载；卡片稳定 season ID。
- **无障碍**：播出状态、会员/付费、追番状态有文字语义。
- **当前差距**：首页、时间表、追番和搜索集中于大 Screen，局部状态复杂。
- **验收**：切类型、追番未登录、某 section 失败、详情返回；预期局部状态互不遮挡。

## P050 番剧播放器档案

- **用户目标**：播放指定季/集，切集、选择画质并继续追番。
- **入口与出口**：番剧详情/历史进入，携带 seasonId/epId/续播；出口到登录、详情和返回来源。
- **信息层级**：媒体 > 集数/标题 > 播放控制 > 画质/弹幕 > 下一集。
- **文字线框**：`番剧媒体 / 状态层 / 进度控制 / 选集与设置`。
- **设备适配**：嵌入、横屏全屏、Expanded/1600dp 保持选集与媒体可达。
- **组件清单**：`BangumiPlayerScreen`、player view/controls、quality menu、选集、错误内容、overlay host。
- **状态矩阵**：首次加载=校验剧集与播放源；刷新=不重建 session；正常=播放；部分数据=弹幕/元信息局部失败；空=无剧集按限制/错误；失败=源失败重试；离线=按缓存；未登录=登录限制；权限不足=会员/区域/版权原因；禁用=不可用清晰度/集；分页加载/结束=选集若分页。
- **交互和返回**：切集更新当前项与续播；全屏先退出；后台/PiP一致；失败保留选择。
- **权限/登录**：会员画质与剧集权限准确，不展示账号无权选项为可点。
- **性能**：session 单一，切集复用合理资源；弹幕按前台与设置加载。
- **无障碍**：集数、当前集、播放/暂停、画质限制可读。
- **当前差距**：番剧控制层与普通视频尚有重复状态/组件。
- **验收**：普通/会员限制、切集、续播、全屏/PiP、源失败；预期集数与媒体状态不串。

## P051 音乐详情档案

- **用户目标**：查看音乐/音频信息并开始播放或进入关联视频。
- **入口与出口**：内容音乐入口进入，携带 sid；出口到播放、关联视频和返回。
- **信息层级**：封面/标题/作者 > 播放动作 > 关联信息/曲目。
- **文字线框**：`顶部栏 / 音乐头 / 主播放 / 关联内容`。
- **设备适配**：Compact 纵向，Expanded 头与内容并排，封面限制尺寸。
- **组件清单**：`MusicDetailScreen`、封面、`AppPrimaryButton`/播放按钮、元信息、状态组件。
- **状态矩阵**：首次加载=头占位；刷新=保留；正常=详情；部分数据=封面/关联缺失；空=无可播源说明；失败=重试；离线=缓存可用性；未登录=按内容权限；权限不足=版权/地区说明；禁用=不可播；分页加载/结束=通常不适用。
- **交互和返回**：播放只创建一个 session；关联视频进入后返回恢复。
- **权限/登录**：按实际音质/内容限制。
- **性能**：封面按尺寸、背景效果降级。
- **无障碍**：标题、作者、播放状态和限制可读。
- **当前差距**：同一 Screen 还承载原生音乐变体，职责需持续明确。
- **验收**：有效、无源、离线、关联视频；预期播放与错误清楚。

## P052 原生音乐播放档案

- **用户目标**：用标题、bvid、cid 直接播放视频中的背景音乐，并可回到原视频。
- **入口与出口**：内容音乐入口进入；出口到当前视频和返回来源。
- **信息层级**：音乐标题/封面 > 播放进度/控制 > 回到视频。
- **文字线框**：`顶部栏 / 封面标题 / 进度控制 / 关联视频动作`。
- **设备适配**：与音频模式一致的稳定封面/控制布局。
- **组件清单**：`MusicDetailScreen` 原生重载、`MusicPlayerContent`、进度、模式控制。
- **状态矩阵**：首次加载=解析 bvid/cid；刷新=不适用；正常=播放；部分数据=标题/封面缺失；空=参数无效按错误；失败=源失败；离线=缓存判断；未登录=按源权限；权限不足=音质限制；禁用=无队列动作；分页加载/结束=不适用。
- **交互和返回**：回视频传递当前 bvid/cid，避免双 session；后台控制同步。
- **权限/登录**：通知/后台按系统要求。
- **性能**：复用音频播放器，不同时创建视频 surface。
- **无障碍**：标题、控制、回到视频动作准确。
- **当前差距**：与 P047 的队列、背景和控制存在可复用点，但入口参数不同。
- **验收**：从视频音乐入口进入、切后台、回视频；预期媒体连续且只有一个 session。

<a id="p058"></a>
## P058 直播间档案

- **用户目标**：观看指定直播间、查看主播/弹幕并控制播放。
- **入口与出口**：直播列表、动态或深链进入，携带 site/room/title/uname；出口到主播空间和返回来源。
- **信息层级**：实时媒体与直播状态 > 返回/控制 > 主播/房间信息 > 弹幕与互动。
- **文字线框**：`实时媒体 / 控制层 / 主播信息 / 弹幕或聊天区`。
- **设备适配**：Compact 嵌入/横屏全屏；Expanded 媒体与聊天可并排；1600dp 不拉伸聊天行。
- **组件清单**：`LivePlayerScreen`、HLS 播放、直播控制、弹幕/聊天、信息 Dialog、状态层。
- **状态矩阵**：首次加载=连接房间/播放源；刷新=重连保留房间；正常=直播中；部分数据=弹幕/主播信息失败不停止流；空=房间不存在按错误；失败=网络/源重试；离线=明确不可实时播放；未登录=可看则降级，互动引导；权限不足=发言/区域限制；禁用=已下播/禁言；分页加载/结束=聊天历史按需，直播流不使用结束分页。
- **交互和返回**：重连不重复播放器；横屏返回先退全屏；聊天手势不抢进度/返回；主播跳转保留房间状态按策略。
- **权限/登录**：发言/关注需登录；网络与本地设备权限按投屏需求。
- **性能**：视频、弹幕、聊天各自节流；后台行为明确；离开释放实时连接。
- **无障碍**：直播中/已下播、播放控制、主播与聊天输入可读；高频弹幕不持续打断读屏。
- **当前差距**：直播控制按钮是领域私有实现，与公共 48dp/状态合同需核对。
- **验收**：HLS 起播、断网重连、下播、横屏、返回重进、弹幕；预期不半加载卡死或重复连接。

<a id="p059"></a>
## P059 番剧详情档案

- **用户目标**：了解番剧信息、选择季度/剧集、追番并进入播放。
- **入口与出口**：首页、搜索、动态、历史进入；出口到番剧播放器、登录、用户/相关内容和返回。
- **信息层级**：封面标题/状态 > 主播放/续播 > 剧集选择 > 追番互动 > 简介/推荐。
- **文字线框**：`顶部栏 / 番剧头 / 主操作 / 季度与选集 / 简介推荐`。
- **设备适配**：Compact 纵向；Expanded 媒体信息与选集并排；选集触摸区 48dp。
- **组件清单**：`BangumiDetailScreen`、详情头、选集、追番按钮、Dialog、推荐卡、状态组件。
- **状态矩阵**：首次加载=头+选集占位；刷新=保留选择；正常=详情；部分数据=推荐/互动局部失败；空=无可用剧集说明；失败=重试；离线=缓存元信息；未登录=公开详情，追番/受限播放引导；权限不足=会员/区域/版权；禁用=不可用剧集；分页加载/结束=选集/推荐按需。
- **交互和返回**：季度/版本切换不串集；追番失败回滚；播放器返回恢复当前季/集。
- **权限/登录**：会员和追番限制准确；不能把受限集显示为可直接播放。
- **性能**：头与选集分开加载；封面/推荐按尺寸；选集列表稳定 ep ID。
- **无障碍**：播出/会员/追番、当前季集与禁用原因可读。
- **当前差距**：详情组件多且直接主题消费较多，双主题映射需逐项验收。
- **验收**：多季度、会员限制、追番失败、切集播放返回；预期选择与账号状态一致。
