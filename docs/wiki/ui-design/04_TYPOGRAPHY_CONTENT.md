## 初学者解释

排版不只是字号。它还包括“先看什么、后看什么”、一行能放多少、文字变长时怎么办、系统字体放大后会不会重叠。文案则决定用户是否知道发生了什么以及下一步能做什么。

## 规范要求

### 信息层级

| 层级 | 用途 | 规则 |
|---|---|---|
| 页面标题 | 标识当前主要目的地 | 每页一个主要标题；容器内禁止使用英雄级超大字 |
| 区块标题 | 分隔同页内容组 | 与相邻正文保持清楚间距，不伪装成按钮 |
| 项目标题 | 视频、设置、用户或消息名称 | 优先保留识别信息，空间不足时末尾省略 |
| 正文 | 描述、评论、说明 | 使用主题正文样式并支持系统字体缩放 |
| 辅助文字 | 时间、统计、说明 | 可弱化但仍需可读，不以极低透明度隐藏 |
| 标签 | 状态、等级、类型 | 短而明确，不重复标题已经表达的信息 |

- **必须**优先使用 `MaterialTheme.typography` 或设计系统映射后的文字样式。
- **应该**通过字重、颜色和空间建立层级，而不是堆叠很多相近字号。
- **禁止**用 viewport 宽度动态缩放字体；文字大小应由语义和系统字体比例决定。
- **禁止**使用负字间距；字间距固定为 0，除非第三方品牌字标有正式资产规则。
- **禁止**在紧凑卡片、侧栏、设置项中使用页面级大标题。

### 文本伸缩与截断

- 按钮文字**必须**完整或合理换行；不能被图标、计数或边界遮挡。
- 单行视频标题可以末尾省略，但详情页完整标题**必须**可展开或完整读取。
- 用户名、标题等最长单词若超出容器，应允许换行、宽度约束或省略，不能覆盖相邻操作。
- 系统字体放大到 1.3 倍时，主要功能仍应可操作；更大字号下可以增加行数和页面高度。
- 时间、播放量等数字应明确单位，不能仅靠颜色区分类别。

### 中文 UI 文案

| 场景 | 推荐结构 | 示例 |
|---|---|---|
| 命令 | 动词或动词+对象 | “重试”“删除缓存” |
| 开关标题 | 描述启用后的状态 | “自动播放下一集” |
| 空状态 | 说明没有什么 + 可选下一步 | “还没有收藏的视频” |
| 错误 | 发生了什么 + 可执行恢复 | “加载失败，请重试” |
| 权限 | 功能原因 + 所需权限 + 拒绝后的结果 | “发现投屏设备需要附近设备权限” |
| 破坏性确认 | 明确对象与不可逆结果 | “删除这条下载任务？” |

- **必须**使用用户能理解的结果描述，不能直接展示异常类名或堆栈。
- **必须**让错误、空状态和权限提示说明下一步；没有可恢复动作时要诚实说明。
- **应该**使用简短、直接、礼貌的中文，避免重复标题。
- **禁止**用“确定吗？”作为缺少对象和后果的确认文案。
- **禁止**把使用说明、快捷键或组件设计解释长期显示在正常业务界面里。

### 设置页文案

- 设置标题描述用户能理解的对象或开启后的结果，例如“主题模式”“自动播放下一集”。
- 当前值只显示一次：优先放在 trailing、选中标记或选项弹层；禁止同时写成“主题模式：跟随系统”和 trailing“系统”。
- 说明只解释影响、限制、依赖或不可逆结果，不解释组件实现和设计规范。
- “使用 Miuix BasicComponent”“MD3 官方推荐 onSurfaceVariant”等实现术语不得常驻普通设置页；确需面向高级用户时放入高级说明或文档。
- 普通设置说明默认不超过两行；超过两行时应缩短、移入详情/帮助，或拆成更清楚的设置。
- 导航箭头、下拉指示和当前值不得表达重复动作；同一行只保留一个明确的主交互。

## 正确与错误示例

正确：“网络连接失败。检查网络后重试。”按钮为“重试”。  
错误：“Error -1”，按钮为“确定”。

正确：“删除下载任务？已下载的本地文件也会移除。”  
错误：“是否操作？”

## Compose 短示例

```kotlin
AppText(
    text = title,
    style = MaterialTheme.typography.titleMedium,
    maxLines = 2,
    overflow = TextOverflow.Ellipsis
)
```

## 代码映射

- 主题文字基线：`Type.kt`
- 公共文字入口：`AppPrimitiveComponents.kt` 中的 `AppText`
- 业务格式化：各 feature 的格式化策略或 `FormatUtils`
- 可访问语义：Compose `semantics` 与组件 `contentDescription`

## 当前差距

旧页面存在 11sp、12sp、13sp、14sp、15sp、17sp 等局部字号和透明度组合，尚未全部归入语义层级；部分错误文案只有失败结论，没有恢复建议。当前规范不把这些硬编码值自动升级为 Token。

## 验收方法

1. 在 360dp 宽度、默认字号和 1.3 倍字号下检查按钮、设置项、卡片与弹窗，无重叠或不可点击内容。
2. 只读错误或空状态文字，用户应能知道发生什么和可以做什么。
3. 隐去颜色后，仍能从文字、图标或形状判断选中、错误和禁用状态。
4. 页面标题、区块标题、项目标题和辅助文字在视觉上有稳定层级。
